# Telephort device skill

Cursor skill for creating a Telephort device the same way the create form does: internet, model, GPU, keybox, then an optional Play Store update or sign-in.

The skill file is `.cursor/skills/telephort-device/SKILL.md`.

## Install

Copy the folder `.cursor/skills/telephort-device` into the Cursor project where the Telephort MCP server is already connected.

Connecting the MCP URL does not install this skill. The agent only follows it in a project that contains this folder.
